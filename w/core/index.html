Talk to us

Questions, answered.

How long does migration take?

Most teams change one base address and one key. If you use the common chat API shape, your existing code and SDKs keep working.

What happens when a region goes down?

Requests move to the next closest region within 200 ms. You do not need to configure anything, and you can pin regions if your data must stay in one place.

Do you train on our data?

No. Prompts and outputs are not stored unless you switch on tracing, and they are never used for training.

Can we run our own model?

Yes. Upload weights or a fine-tune and it gets the same endpoint, autoscaling and observability as every hosted model.
